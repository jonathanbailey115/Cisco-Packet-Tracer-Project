# File Locks

Git can't merge `.pkt` files, so only ONE person may edit a given file at a time.

**Before editing:** pull, add your name below, commit + push.
**After editing:** commit your .pkt + configs, remove your row, push.

If someone's name is here, don't open that file for editing — message them.
